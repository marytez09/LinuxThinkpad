# RAM Upgrade Process
- Removed battery and power cable
- Removed screws with Phillip screwdriver
- Removed 4GB Samsung PC3-12800 x1
- Replaced with Timetec 8GB DDR3-1600 x2
- Placed plastic covering and placed screws to secure

# SSD Upgrade Process
- Removed battery and power cable
- Slid out old SSD and removed rubber covering
- Applied rubber covering to new SSD
- Inserted new SSD into SSD slot
