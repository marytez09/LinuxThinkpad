# Display Replacement Process
## SAFETY!! Remove battery and power cables before manipulating components
- Removed sticker tabs covering screws
    - Unscrewed both bottom screws

- Gently lift off plastic covering
    - Used a thin plastic guitar pick and slid around edges of screen
    - Remove plastic cover

- Unscrew the four screws securing display
    - Flipped over display and removed adhesive strip
    - Unplugged display connector

- Placed new screen over keyboard with the screen facing downwards
    - Reconnected new cable to cable connector
    - Flipped over screen and removed screen cover
